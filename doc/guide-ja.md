# Moonshine V2.3.3 Frame By Frame 日本語版

ユーザーガイド

Moonshine は、動きの確認、TASの作成、走行の比較に使う練習機能を提供します。手作業で定義したレベル内チェックポイントにより、ゴールを含めて1ルートにつき最大8区間を計測できます。

## 日本語表示

標準ダウンロードでは、日本版サンシャインを選んでも、ランチャーとゲーム内のMoonshineメニューは英語のままです。サンシャイン本来の言語は変更しません。

日本語専用ダウンロードでは、選んだゲームの地域に関係なくランチャーを日本語で表示します。ゲーム内のMoonshineメニューは日本版のみ日本語になり、北米版・欧州版では英語のままです。Task Editionの翻訳と、日本語テスターからの用語修正を反映しています。ゲーム内の簡易ガイドは **System > Moonshine guide** から開けます。一部の状態表示・診断メッセージとランチャー内蔵ガイドの本文には英語が残ります。

`boot.dol` と同じフォルダーの `language.txt` も配布ファイルと一緒に更新してください。標準版には `en`、日本語版には `ja` が入っています。ファイルがない場合や内容が正しくない場合は英語になります。日本語版のゲーム内表示には、同じフォルダーの `ja_ui.bin` も必要です。これがない場合や破損している場合も英語に戻ります。設定ファイルの項目名やPB・実績の識別番号は変わりません。

このガイドでは英語版と照合できるよう英語のメニュー名も使います。主な対応は **Practice＝練習、Runs＝走行、Records＝記録、Ghosts＝ゴースト、Display＝表示、System＝システム、Frame advance＝コマ送り、Free camera＝フリーカメラ、Save to＝保存先、Load from＝読込元** です。ボタンの割り当て方や操作は両言語で同じです。

## インストール

ZIP 内の `apps` フォルダーを SD カードの一番上にコピーします。ランチャーの場所は `apps/moonshine_launcher` です。配布ファイルだけを更新し、既存のテーマ、音楽、設定、記録、ゴーストは残してください。対応する日本・北米・欧州版のディスク、または自分で用意したゲームイメージを使用します。ランチャーと mod ファイルは同じリリースのものを使用してください。**公開版 V2.3.1/V2.3.2 のSDステートとTASプロジェクトは、従来のリージョン・エピソード・状態の確認を通れば使用できます。以前の開発版は対応するビルドが必要です。** 設定・記録・ゴーストは引き続き使用できます。

日本語版専用ZIPには `apps/moonshine_launcher` と、任意の国旗背景 `Moonshine data/theme/background.png` が入っています。国旗を使う場合だけ背景もSDカードへコピーしてください。すでに自分のテーマを使っている場合は、その内容を残してアプリだけ更新できます。標準版にはテーマは含まれません。

Homebrew Channel から Moonshine Launcher を開きます。**Version** でゲーム版を選び、**Path** で SD・USB の ISO/CISO、または実ディスク用の **Disc Drive** を選びます。**Launch Game** で起動します。Auto Boot が有効な場合は、起動中に B を押し続けるとランチャーのメニューへ戻れます。

テーマは起動元デバイスの一番上にある `/Moonshine data/theme` から先に読み込みます。フォルダーがない場合は、デバイスの準備ができた後で自動作成します。自分の `background.png` と `bgm.mp3` はここに入れてください。既存のファイルは残し、フォルダーを作れなくても起動は続けます。起動時は前回選んだゲームの保存先だけを確認し、使っていないSD・USBの一括検出を待ちません。別のデバイスはゲームの保存先で選んだときに接続します。音楽はカーネルの準備後に開始します。読み込み中は状況を示す文字を表示し、暗いテーマでは縁取りを付けます。

設定や mod の保存データは、ランチャーを起動したデバイスに保存されます。たとえばランチャーが SD、ゲームが USB にある場合も、設定は SD に保存されます。日本・北米・欧州版の設定とボタン割り当てはそれぞれ独立しています。初回起動時に既存のデータを `/Moonshine data` へ自動で移行します。更新前のファイルは残し、自分で名前を変更する必要はありません。

## 保存フォルダー

Moonshineのデータは、ランチャーを起動したデバイスの `/Moonshine data` にまとめて保存します。アプリ本体は `/apps/moonshine_launcher` のままです。

| Moonshine data内の場所 | 内容 |
| --- | --- |
| `moonshine.ini` | 設定、レイアウト、ボタン割り当て |
| `moonshine_*.bin` | 記録、実績などの練習データ |
| `theme/` | `background.png` と `bgm.mp3` |
| `ghosts/` | ゴースト。受け取りは `import/`、共有用の出力は `share/` |
| `states/` | 名前を付けたSDステート |
| `tas/` | 保存したTASプロジェクト |
| `crashes/` | クラッシュ報告 |
| `backups/` | 移行やバックアップ時に保管したファイル |

## メニュー

標準のメニュー操作は Y + Start です。L/R で上位タブ、C スティックで項目を移動し、A で選択、B で戻ります。

- **Quick**：Shined に登録したお気に入り。新しい名前付き設定も登録できるようになり、フリーカメラの移動速度・左右反転・視点感度・HUD非表示も対象です。以前の星はそのまま残ります。
- **Practice**：先頭の TAS projects で一時停止・コマ送り・TASを操作します。続いて Free camera、ステート、練習ルール、乱数、ゲーム設定があります。
- **Runs**：IL、プレイリスト・連続成功、記録、PB Safety、タイマー・スプリット設定。
- **Records**：実績と練習の統計。Runs 内のショートカットからも開けます。
- **Ghosts**：ゴーストとの競走、観察、保存、管理。
- **Display**：表示位置、HUD、タイマー・スプリット、外見。
- **System**：ボタン割り当てと簡易ガイド。

新しいIL・連続成功の試行では、その試行の練習設定を確認します。前のステージで一時停止したことだけでは、新しい通常の試行を対象外にしません。連続成功で試行が認められなかった場合は、カウンターの横に理由を短く表示します。

## 練習用一時停止とコマ送り

**Practice > TAS projects（TAS管理）** を開き、**Pause / Resume（一時停止 / 再開）** または **Advance one frame（1コマ進める）** を選びます。選択中の操作には現在のショートカットが表示され、**X** で変更、**Z** で解除できます。System > Button binds からも変更可能です。一時停止・コマ送りを使うだけなら、New TAS を始める必要はありません。

| 標準操作 | 機能 |
|---|---|
| 十字キー下 | 練習用一時停止・再開、停止予約の取り消し |
| 十字キー上 | まず一時停止し、次の入力から一回ずつコマ送り |
| 未設定 | フリーカメラと、編集・再生・開始地点・中間地点の7つのTASショートカット |

上の表は新しい設定の標準値です。以前の L を使う割り当ても含め、既存の設定は保持します。Z の既存機能も維持します。

ロード中、開始演出・ムービー中などマリオを操作できない間でも Pause または Step を押して停止を予約できます。**Armed** は、マリオを操作できるようになった瞬間に停止するという意味です。ボタンを押し続ける必要はありません。Pause をもう一度押すと取り消します。待機中に Step を繰り返しても余分なコマ送りは追加しません。

練習用一時停止では、ゲームプレイと QFT が止まります。Step 一回で通常のゲーム一コマ分が進み、QFT もその分だけ進みます。音楽やゲーム内部の時計は動き続けます。この機能を使った試行では、QFT の横に小さな **TAS** を表示します。通常の PB 対象外となるため、新しい試行を始めるにはステージを再開してください。

練習用一時停止・コマ送り中は、ステートを読み込んだ後も Sunshine タイマーと小型 QFT が同じコマの時刻を表示します。表示する桁数は異なるため、小型 QFT の `11.845` は Sunshine タイマーでは `11.85` になる場合があります。通常プレイの QFT の計算式と、計測開始・終了などの処理は変更していません。

フリーカメラが **Off** なら、A を押しながら Step を押して、そのコマでジャンプできます。A を押したまま Pause を始めることもでき、他のゲーム用ボタンも Pause・Step と同時に使えます。後のコマでもう一度 A を押したい場合は、A を離してから押し直し、その後 Step を押してください。A を離さなければ、押しっぱなしとして扱います。Pause・Step 用コンボ自体はマリオの操作に使われず、割り当てに L/R が含まれる場合は離すまでトリガー入力も抑えます。メニューから Step または Resume を選んだ場合は、A を離すと進みます。

停止中は Step が優先されます。たとえば A+B を押しながら十字キー上でコマ送りしても、B+十字キー上のリスタートは発動しません。A+B はマリオの操作に残ります。通常プレイ中は、これまでどおり B+十字キー上でリスタートできます。

スピンはメインスティックを自分で操作します。各 Step を押す前に、次の方向へスティックを倒してください。スティックでマリオを操作できるよう、フリーカメラは Off にします。

## フリーカメラ

**Practice > Free camera** で On にすると、通常のゲームプレイを自動で一時停止します。メインスティックで移動、C スティックで視点、L/R のアナログ入力で下降・上昇します。**Movement speed** で0.25～4倍の移動速度を保存できます。X は一時的な加速です。**Look sensitivity（視点移動の感度）** は別の設定で、Cスティックによる視点の回転を0.25～4倍に調整します。

同じページの **Resume gameplay（ゲームを再開）** で、フリーカメラを使いながらゲームを通常速度で動かせます。**Pause gameplay（ゲームを一時停止）** で再び停止します。どちらの場合もスティックはカメラを操作します。両スティックとも全方向に対応し、中心付近はゆっくり、外側は速く動く滑らかな調整になりました。

**Camera smoothing（カメラの補間時間）** は、スティックを倒す・方向を変える・離すときの移動と回転を滑らかにします。**0.1～1.5秒**を0.1秒刻みで選べます。長いほど動き始めと停止がゆっくりになります。標準は **Off** で、すぐに反応・停止します。

**Hide all HUD（すべてのHUDを隠す）** をOnにすると、フリーカメラ中のゲームとMoonshineの表示を隠します。modメニューは開けます。この設定かフリーカメラをOffにすると、元の表示に戻ります。

メインスティックの左右が逆に感じる場合は、同じページの **Reverse sideways** を On にしてください。左右移動だけを反転し、C スティックの視点操作は変更しません。標準は Off です。Recenter でゲーム本来の視点へ戻せます。フリーカメラを Off にすると本来の視点へ戻り、ゲームの一時停止・再開の状態はそのままです。

通常の Start ポーズ中にも使用できます。フリーカメラを使いながらコマ送りもできますが、**Camera On の間は Mario input Off** となり、A やスティックはマリオの操作に反映されません。ジャンプやスピンをコマ送りする前に Off にしてください。カメラの変更は一時的な描画状態で、ゲーム処理やステート操作前に復元されます。場面が変わると終了します。

Ghost Watch と Watch2 でも一時停止・コマ送り・フリーカメラを使用できます。一時停止中はゴーストの再生位置も止まります。Watch を再開してもフリーカメラを維持できます。B または Start で Watch を終了します。メニュー用コンボで mod メニューを開いた場合は終了しません。

## 3つのステート

**Practice > Savestates** で、保存先の **Save to** と読み込み元の **Load from** を別々に選べます。A または C スティック左右で切り替えます。選択だけでは保存・読み込みは行いません。たとえば Save to を State 1、Load from を State 2 にすると、State 1 を上書きしながら State 2 からの練習を続けられます。

3つのステートには Saved（保存済み）または Empty（空き）と表示されます。**System > Button binds** の **Savestate: cycle save slot** と **Savestate: cycle load slot** は、各選択を切り替える任意のショートカットです。標準では両方とも未設定です。以前の割り当てに対応する **Savestate: cycle both slots** も残っています。

このランチャーでは、3つのステートが **17.938 MiB** のメモリを共有し、圧縮して保存します。必要な容量は、場面や保存時点までのゴースト録画の長さによって変わります。自動削除はありません。上書き時は、新しい内容が収まると確認できてから、古いステートの領域も使います。収まらない場合は、上書きしようとしたステートも含め、以前の内容をすべて残します。**Clear save slot** は、確認後に Save to のスロットを消します。他のステートは残ります。読み込みには、保存時と同じステージとエピソードが必要です。保存・読み込みの処理中は、ゲームが一時的に止まる場合があります。成功時の通知とは別に、Savestate errorsでエラー表示も切り替えられます。読み込めない場合は、スロット番号と正確なメッセージを報告してください。日本版のState 3だけに起きる問題は、現時点では確認できていません。

ゲームを終了したり再起動したりすると、3つのメモリスロットは空になります。後で使いたいステートは、終了前に別途 SD へ保存してください。

## SD にステートを残す

**Load** のショートカットを押したままにすると、読み込み後もゲームプレイを止めておけます。離すと動き出します。読み込み前から練習用一時停止を使っていた場合は、離しても停止を続けるため、Resume または Step を使ってください。

保存した場面がイントロ中の場合は、まずイントロが終わるまで進みます。Load を押し続けると、マリオを操作できる最初のコマで止まります。早めに離すとそのまま続行します。読み込み前から練習用一時停止を使っていた場合は、操作可能になると再び一時停止します。

1. 通常のステートを保存し、**Save to** でそのメモリスロットを選びます。
2. **Practice > Savestates > SD states > Save memory state to SD** を選びます。名前を入力して Start で確定し、保存完了まで待ちます。ランチャーの起動元デバイスの `/Moonshine data/states` に、新しい `.mss` ファイルを作ります。名前入力は X + Start で中止できます。
3. 再起動後は、同じ mod ビルド・ゲーム版・ランチャー設定で起動し、同じステージとエピソードへ入ります。秘密コースは、入る前の親エピソードも一致させます。
4. **SD states > Refresh / first page** で一覧を開き、ファイルを選んで次の操作を行います。

| ファイル上で押すボタン | 操作 |
|---|---|
| **Y — Load from** | 通常の Load ショートカットの読み込み元にします。メニューを閉じて Load を押すと復元します。3つのメモリスロットはそのまま残ります。 |
| **A — Import** | 確認後、**Save to** のメモリスロットにコピーします。**Load from** は変わりません。使うときは、読み込み元をそのスロットに切り替えてください。 |
| **Start — Rename** | 表示名を変更します。Start で確定、X + Start で中止します。 |
| **X — Delete** | SD ファイルの削除を確認します。キャンセルすれば残ります。メモリ内のステートには影響しません。 |

SD を読み込み元にすると、その都度ファイルを読むため、メモリからの読み込みより時間がかかる場合があります。今回から、3スロットが満杯でも、現在の場面と設定に合う正常なメモリステートが1つあれば、大きな SD ファイルを読み込めます。そのメモリステートを読み込み失敗時の復旧用として残します。Load from でそのスロットを選ぶ必要はなく、保存済みの3スロットはすべて保持されます。

復元の途中で SD 読み込みに失敗した場合は、復旧用ステートを読み込み、使用したスロット番号を表示します。適切な復旧用ステートがなく、一時領域にも収まらない場合は、安全に読み込みを拒否します。A でメモリに取り込む場合は、従来どおり保存先の空き容量が必要です。

読み込まれているゲームデータの配置も確認するため、ステージ名が同じだけでは読み込めない場合があります。対応していない状態、互換性のないファイル、破損したファイルは、既存のメモリスロットを置き換える前に拒否します。SD ステートは保存したビルドとゲーム設定専用で、ゴーストのような別リージョン間の共有用ファイルではありません。

転送またはキャンセルが完了するまで、保存デバイスを取り外さないでください。前のビルドでは、テスターが Wii 実機の再起動後に SD ステートを復元できたと確認しています。コマ送りを含むゴーストの継続、2つのタイマーの一致、色設定の保存も確認済みです。今回の新しいファイル操作については、引き続きさまざまな場面での結果を TESTING.md の最新項目から報告してください。

## TASの記録・編集・保存

**Practice > TAS projects（TAS管理）** を開きます。入力記録、開始地点、二つの中間地点を、一つの名前でまとめて管理します。

1. 記録を始めたい場所で **New TAS（新しいTAS）** を選びます。開始地点と乱数は自動で保存されます。確定に使ったAを離してください。StepまたはResumeを使うまでゲームは停止しています。
2. マリオのボタンを押しながら **Step** で一コマ記録するか、**Resume** で通常の操作を記録します。メニューを開くと作業が一時停止します。
3. やり直したい動きの前に **Checkpoints > Save Checkpoint 1** で中間地点を保存します。後から **Go to Checkpoint 1** を選ぶと、入力記録もその地点まで戻ります。**Continue（編集を続ける）** を選び、新しい続きを作ってください。中間地点2も使えます。
4. **Replay（再生）** は開始地点から入力を再生します。BまたはStartで再生を中止できます。Continueを選んだ後も、StepまたはResumeを使うまで停止しています。
5. **Save TAS（TASを保存）** を選び、初回は名前を入力してStartで確定します。入力記録全体、開始地点、作成済みの中間地点をまとめてSDへ保存します。現在地に新しい中間地点を作る操作ではなく、追加の空きスロットも不要です。次回以降は同じTASを更新します。保存完了の表示を確認してからゲームを終了してください。
6. 再開するときは同じビルド・ゲーム版・設定を使い、**Open TAS（TASを開く）** で名前を選びます。選択中の中間地点または開始地点が現在のエリア・エピソードで読み込める場合は、そこで一時停止し、それ以降の入力記録も再生用に残します。合う地点がない場合はマリオを動かさず入力記録だけを開きます。そのまま保存し直すことができ、開始したエリアへ戻ればReplayを使えます。

**Go to Beginning（開始地点へ戻る）、Go to Checkpoint（中間地点へ戻る）、Open TAS（TASを開く）の後は、一時停止したまま編集を始められます。** Continueを選ばなくても、StepまたはResumeで新しい入力を記録できます。最初の新しい入力を記録するまでは、以前の続きもReplay用に残ります。保存や読込だけで記録が短くなることはありません。SD上の記録は、Save TASで保存するまで変わりません。

**Continueは一時停止したまま待機します。** 次の入力を決めてからStepまたはResumeを使ってください。Stopで記録を止めた後やReplayが最後まで終わった後は、再び記録するためにContinueを選びます。通常のStepだけで、止めた記録を勝手に編集することはありません。

**中間地点の保存はメモリ内のやり直し地点を作る操作です。TASを保存すると、再起動後も作業が残ります。** 保存先は `/Moonshine data/tas` です。開始地点と中間地点を別々にインポートする必要はありません。通常のSDステートとは別の一覧です。

保存済みの中間地点を上書きするときは、メニューでもショートカットでも確認します。**A** で置き換え、**B** で以前の中間地点を残します。**Save TAS** は、名前を付けたSD上のTASをそのまま更新します。中間地点の上書き確認とは別の操作です。

Continue、Replay、Go to Beginning、または中間地点の保存・読込を選び、**X** でショートカットを割り当て、**Z** で解除できます。この7つのTASショートカットは、すべて標準では未設定です。画面上部には **200 / 4096コマ** のように、記録済みのコマ数と上限を表示します。

Open TASの一覧では、名前を選んで **Start** で名前を変更、**X** でSD上のTASを削除できます。削除には確認があります。現在メモリにある中間地点は残りますが、ゲーム終了後も残したい場合はもう一度TASを保存してください。

TASは通常のステートと同じ三つのメモリスロットを使います。空きがなければ、置き換える通常ステートを選ぶ確認が出ます。キャンセルすれば残せます。TAS画面では開始地点と中間地点を名前で扱うため、スロット番号を覚える必要はありません。

秘密コースへ入るなどの通常のエリア移動でも記録を保持します。開始演出、フェード、会話、ムービー中の入力も、スキップを押したタイミングごと記録・再生します。ポンプのムービーも対象です。読み込み待ちの時間は入力コマ数に含めませんが、入力を受け付ける演出・ムービーのコマは **4096コマの上限** に含めます。エリアとムービーの切り替わりは合わせて **32回まで** です。未対応の移動や上限に達した場合も、保存できるよう入力記録を残します。

開始演出とムービーは通常の速度で進みます。その間に Pause または Step を押すと、マリオを操作できるようになった時点で停止します。ムービー自体をコマ送りする機能ではありません。

Checkpoints などのTASサブメニューからも、普段の Close ショートカットで閉じられます。ただし、新しいショートカットの入力を記録している間は、そのボタンも割り当て用として受け取ります。編集を完了または取り消し、ボタンを離してから Close を押してください。

中間地点の **Other area（別エリア）** は、保存が消えたという意味ではありません。その地点と同じエリア・エピソードへ移動してから読み込んでください。**Replay** と **Go to Beginning** は、TASを開始したエリア・エピソードへ戻ってから使います。自動でそのエリアへ移動する機能ではありません。

入力再生は実験的機能です。ゲーム状態が記録と異なった場合、最初に異なったコマを **DESYNC fN** と表示し、その後の入力も再生します。これは元の動きからずれた可能性を示す警告で、自動で修正する機能ではありません。BまたはStartで再生を止められます。破損した入力ファイル、ゲームプレイに影響する設定の不一致、不適切なエリアやステートの読込は引き続き拒否します。タイマー位置やカメラの表示設定などは変更できます。別リージョン・別ビルドのTASプロジェクトは使えません。完成した試行を共有する場合は、ゴーストを書き出してください。

**TAS banner（TASバナー）** は標準でOnです。**Practice > TAS projects** または **Display > Other HUD** から変更でき、Quickのお気に入りにも登録できます。Offにすると大きな進行状況・操作説明の帯を隠します。再生中にずれが見つかった場合の小さなDESYNC表示は、Offでも残ります。**f0** は開始時点ですでに状態が異なったことを表します。

記録と同じ移動先への到着が早い・遅い場合も、警告しながら残りの入力を順番どおり再生します。現在のエリアと入力記録上のエリアがずれている間は、中間地点での編集が一時的に使えない場合があります。**Save TASで記録全体を保存することはできます。** 編集するときは、読み込める既存の中間地点へ戻ってください。記録と異なる移動先への再生は引き続き停止します。

## ゴースト入力とスプリット比較

Ghost Watch はムービーを自動でスキップし、ゴーストの動きのタイミングを保ちます。ゲームプレイに戻っても Watch は継続し、Pause・Step・フリーカメラを使えます。

**Runs > ILs** の対応する行で **Z** を押すと、開始エピソードを選べます。C スティック上下で選び、A で保存、B で取り消します。対象は7つのメインコースの100枚コイン、Gelato・Noki・Pianta の Hidden、10種類の Full Reds です。選択は JP・US・PAL ごとに保存されます。

新しい手作りスプリットは、未追加だった各ルートと Full Reds に対応しています。変更されていない区間の記録は引き継ぎ、計測内容が変わった区間には新しい記録を使います。

個人ゴーストとインポートはページ表示になり、45件・12件および合計10時間のライブラリー上限はありません。**Personal page** または **Imported page** を選び、C スティック左右でページを切り替えます。A は次ページです。**Save latest ghost** は新しい個人ファイルを保存します。個人ゴーストの空欄を選んだ場合も、**Save latest ghost** の確認が表示されます。既存のゴーストは引き続き利用でき、Watch2 では別ページから二つ目を選べます。

ライブラリーの容量はストレージの空き容量によって決まります。新しいゴーストの録画上限は約10分です。以前の15分までのゴーストも読み込めます。新しい録画にはFLUDDのノズル、照準、実際に水を出したタイミングが含まれます。水滴と地面のしぶきは見た目の再現で、ゲームには影響しません。インポートしたファイルは元のフォルダーに残り、削除や読み込みは選択したファイルを対象にします。

新しいゴーストには、その試行で使われた入力と、既存の対応スプリットの時刻を保存できます。以前の位置情報だけのゴーストも読み込めます。入力情報がなければ、利用不可として表示します。

**Ghosts > Ghost inputs** で Off、Ghost、**Both ghosts** を選びます。Display > Layout editor > Controller inputs と、従来の Other HUD にも同じ設定があります。Both ghosts は競走中には自分とゴースト、Watch2 では二つのゴーストの入力を表示します。インポートしたゴーストがマリオを操作する機能ではありません。

練習用一時停止、フリーカメラ、コマ送りを使用したゴーストは **TAS** と表示します。停止していた時間を再生から除くため、カメラ調整や入力の検討中の待ち時間は記録に入りません。練習用一時停止中は QFT も止まります。TAS ゴーストは通常の PB 対象外です。

ゴースト録画中のステートには、レベル開始から保存時点までの録画も含まれます。読み込むと、その冒頭部分を戻し、保存後の古い動きを新しい続きで置き換えます。クリア後は、レベル全体の TAS ゴーストとして通常どおり保存・書き出しできます。録画していない状態で作ったステートから、冒頭の動きを補ったり、自動で新しいゴーストを録画したりすることはありません。ローカル入力録画はゴーストとは別の機能です。Save TASで開始地点と中間地点をまとめて保存すると、編集できる入力記録も残せます。

Display > Timer and splits > Timer and splits の比較対象は **Off → PB → SOB → Ghost** です。SOB は保存済みの各区間ベストの累計です。Ghost は選択した競走相手の互換性のあるスプリット時刻を使います。情報が欠ける場合は `--` と表示し、時刻を推測しません。

同じ設定を Runs > Timer and splits からも開けます。最初のページの **Level splits** が表示のオン・オフです。

共有用に書き出したゴーストは、ランチャーのデバイスの `Moonshine data/ghosts/share/` 以下に保存されます。受け取った `.smsghost` は `Moonshine data/ghosts/import/` に入れ、Ghosts からインポートします。内部保存用の `.sgh` は元のフォルダーに残してください。既存の Full Reds IL は Runs から選べます。秘密コースまでの移動と赤コインをまとめて計測する場合は、フルレベルのルートを選んでください。

## レイアウトと色

Display > Layout editor は、Timers、Controller inputs、Metadata、Native HUD colours、Custom text、Practice feedback、Menu and notifications に分かれています。Rollout と Dust は Practice feedback にあり、HUD and displays > Movement displays からも編集できます。

**Timers > Sunshine timer** で位置・サイズ・不透明度・明るさ、13文字、TIME/TEMPO、背景の帯を編集します。位置は画面全体に移動できます。

最初の **Appearance** で **Original** または **Custom** を選びます。対象を All にするとタイマー全体に適用し、Start で文字や画像を一つずつ選べます。Original はゲーム本来の陰影を保ったまま色を調整し、Custom は指定した色をより直接的に表示します。色を変更しても、選択した Appearance は変わりません。タイマー全体を元の色に戻すには、**All > Appearance > Original** を選び、Hue・Saturation・Lightness をそれぞれ **Z** と確認操作でリセットします。位置・サイズなどの設定は保持します。

共通の色エディターは **Hue（色相）、Saturation（彩度）、Lightness（明度）の HSL** で調整します。色相は0～359度で色を選び、彩度は0%で灰色、100%で鮮やかな色になります。明度は0%で黒、100%で白です。更新しても既存の色は保持します。**Y** を押しながら C スティックを操作すると、4ではなく1ずつ調整できます。A で保存、B で破棄、Z で選択項目のリセットを確認します。

**Native HUD colours** の Health counter colour と Underwater air colour は独立した色設定です。リセットすると元の色へ戻ります。

**Display > Appearance > Mario appearance** にある **Mario colours** と **FLUDD colours** も、同じ Creation エディターを使います。Start で All または個別の部位を選び、それぞれ Original/Custom を切り替えられます。HSL を変更すると Custom になり、Original に戻してもカスタムカラーは後で使えるよう保持します。Keep・Discard・Reset と、Y による1ずつの HSL 調整も利用できます。

| エディター | 対象 |
|---|---|
| Mario colours — 7項目 | 帽子、シャツ、オーバーオール、手袋、靴、サングラス、Sunshine shirt |
| FLUDD colours — 10項目 | 本体の塗装、金属、ベルト、タンク、スプレー・ホバー・ロケット・ターボの各ノズル、噴射する水、水のハイライト |

マリオの肌の色は変えません。帽子とシャツをマゼンタにしたとき、テクスチャの丸め処理で赤い点が混ざる問題を修正しました。水の設定は噴流、ノズル口の霧、着水時のしぶきに適用し、海水やヨッシーのジュースは元の色を保ちます。編集を Keep すると、色と各部位の Original/Custom の選択を次回起動にも引き継ぎます。

**Metadata** では Field gap、Row gap、Fields per row、Value widths を C スティック左右で調整できます。横並びで Fields per row を設定すると、指定した項目数で折り返します。Auto は画面端で折り返します。Stable は桁数が変わっても位置を保ち、Compact は空白を詰めます。文字ごとの色は元の項目に対応したままです。

## レイアウトの保存とタイミング表示

**Jump display** と **Buttslide display** は、それぞれ独立してオン／オフにできます。両方を同時に表示できます。おしりすべり表示は、地面と滑り状態に応じて、ゲームがジャンプを受け付ける時を示します。コマ送り中も使えます。A入力の自動生成や予約は行いません。

**Display > Layout profiles** では、ゲーム版ごとに5つの名前付きレイアウトを保存できます。**Y** で現在のレイアウトを保存し、名前を入力して **Start** で確定します。既存のデータを置き換える前に確認します。**A** で保存済みレイアウトを適用します。表示位置、色、カスタムテキスト、メニュースタイル、マリオとポンプの色などを含みます。ボタン割り当て、練習ルール、記録は変更しません。ランチャーでは **Moonshine data/layouts**、Dolphin ではスロット B のメモリーカードに保存し、再起動後も使えます。

**Display > HUD and displays > Movement displays** の **Jump display** は、直前の着地からジャンプまでを **1f～6f**、それ以降は **Late（遅い）** と表示し、離陸したクォーターフレームも示します。例えば `1f qf2` は、着地の1フレーム後、QF2でジャンプしたことを意味します。着地するたびに数え直します。一時停止中の時間は数えず、ステート読込やエリア移動で表示を消します。

**GB skip timing** は、通常の最大 A ジャンプ後に B を押すタイミングを調べます。ホバー禁止 GBskip の目標は、空中9フレーム、Y約404、V速度約6です。早い・適切・遅い・ジャンプ要確認と、フレーム数・高さ・V速度を表示します。X/Zや、実際にすり抜けたかどうかは判定しません。この画面の Edit、または **Layout editor > Practice feedback** から、GB・ジャンプ・おしりすべりの位置、サイズ、透明度、背景、色をそれぞれ編集できます。壁キック表示の設定は変わりません。

**Fast Any%** のピンナはビーチ、ノーキー3はビンの外から始まります。ヒミツでミスした後もクリアすれば次へ進みますが、そのリトライは通常のフルレベルPBやプレイリストベストにはなりません。単独ILの開始地点は変わりません。

## Dolphin

対応するゲーム版の BPS パッチをクリーンな ISO に適用します。Wii ランチャーの ZIP は Homebrew Channel 用です。mod の設定を保存するには、スロット B のメモリーカードを有効にしてください。ステート読み込み時に汚れを正しく復元するため、Texture Cache Accuracy を Safe に設定します。更新時は Sunshine 本来のセーブと、スロット B の Moonshine 設定ファイルを残してください。

コマ送り機能には新しい Dolphin リリースを使用してください。Dolphin 5.0 の JIT では、一時停止中のメニュー入力が止まる場合があります。

SD states は Moonshine Launcher の保存機能を必要とするため、Dolphin 用 BPS パッチ単体では使えません。3つのメモリスロットは使用できます。標準ダウンロードのBPSでは、日本版を含めMoonshineメニューは英語です。日本語表示には、別配布の日本語専用JPパッチを選んでください。日本語専用パッチには必要な文字とフォントが含まれ、別途 `ja_ui.bin` を置く必要はありません。翻訳データはステートの保存容量を使いません。

## 不具合の報告

報告にはゲーム版、ステージ、設定、再現手順、画面に出るビルドチェックサムを添えてください。`/Moonshine data/crashes` に最近のクラッシュ報告を最大16件保存します。同じ報告のテキスト、`.bin`、`.core` はまとめて保管してください。移行時には以前の報告も保管します。`tools/decode_crash.py` は Python 3 でバイナリ報告を読めます。詳細な報告を作れなくても最小情報の保存を試みますが、電源を切った後まで残すにはストレージへの書き込みが必要です。

MEM1 の予約量は V2.2 より256 KiB増えた768 KiBです。固定タイマー領域、モデル用ヒープ、ステートの領域は分離したままです。最も重いステージでの実際の空きメモリも、実機で確認してください。
