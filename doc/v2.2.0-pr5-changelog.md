# Moonshine V2.2.0 Pre-Release 5

## The House Always Wins

- Fixed saving a new ghost while racing a ghost loaded from the library. The
  loaded opponent no longer replaces or stops the challenger recording.
- Streaking now accepts any Shine collected in the selected episode. Hidden and
  100-coin Shines were removed from the Streaking start list while remaining
  available everywhere else.
- Added `Pinna fruit and coins`, which marks unrevealed spray-hidden items on
  Pinna Beach.
- Added a global `Enemy hurtboxes` display, including Eely-Mouth's teeth.
- Added the classic Dan Salvato position save and load actions to Button Binds.
  A successful position load removes IL credit; saving alone does not.
- RNG settings can now be added to the Shined page without changing their
  selected values.
- Moved Gelato GBS into the Gelato section of the IL menu without changing old
  PB or playlist identities.
- Fixed Bianco 2's Petey-hit splits on the Bianco 1 physical map. The route now
  records rollout, all three hits, and the final Shine in order.
- Dust no longer reports a ground timing during waterslides or on wet ground.
- Fixed the classic input display's stick travel and made Start visible at the
  smallest layout size.
- Added C-stick section jumping to the Settings and IL hubs. Replaced missing
  punctuation in menu labels with visible words for the JP font.

Gameplay timer code was not changed.
