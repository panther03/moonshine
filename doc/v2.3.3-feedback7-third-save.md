# Third-save follow-up — test build 88F62AB9

The user's Wii measurements were 3.870 seconds for Bianco 5's third save and
5.438 seconds for Pinna 3's. Those are the user's measurements, not emulator
results. This update targets a small part of the room-making work, not the
entire delay.

Quick-to-Deflate retained-state repacking no longer calculates the same raw
Adler checksum in both its decoder and its encoder. The encoder must still
finish and match the expected complete checksum before any retained stream is
published. Normal validation/restoration still calculates its checksum, and
structural decoding checks, source CRC admission, output bounds, state identity
and generation checks are unchanged. No state is evicted. Codec formats,
reservations, pool capacity, save policy and QFT are unchanged.

Validation:

- 1,646 host tests passed, including corrupt streams, incorrect expected raw
  checksums, bounded output, retained slots and replacement refusals.
- The private PAL Dolphin repack comparison used the user's captured 15,178,256
  raw-byte state. Two comparisons returned 69,569,945 ticks before and 66,516,730
  after (4.39% less for this isolated operation). All four outputs had identical
  SHA-256 `51acd6a01728d7171afadd534d680f41033c43e7e43e5e578e78ca77e630c2c0`,
  decoded to the exact original state, and preserved the input stream.
- Console and emulator builds fit the existing reservations; JP's mod file is
  548,824 bytes. The package is a candidate/test package, not a published release
  or a new whole-game runtime certification.

This percentage is not a Wii save-time prediction. The candidate/retained
compression passes still dominate crowded saves. A prior experiment stopping
overlarge candidates early was rejected because its weaker size estimates
caused additional compression attempts in existing tests. It is not included.

For a useful Wii check, save three states in Bianco 5 or Pinna 3, time the third
save the same way as before, and confirm all three load. No broad retest is
requested for this narrow change.

Local evidence: `build/v2.3.3-feedback7/host-tests.log` and
`build/v2.3.3-feedback7/repack-ppc.json`.
