# Moonshine V2.2.0 Release Candidate 2

## The House Always Wins

RC2 is a small release-blocker update to the otherwise successful RC1 test.

## Changes from RC1

- Fixed a crash that could occur while drawing a 3D ghost after repeated stage
  loads. Moonshine now refuses to submit an incomplete ghost model and uses the
  existing simple ghost marker instead.
- Made the classic input display's Start symbol slightly smaller so it remains
  distinct from the face buttons.
- Kept all settings, records, ghosts, layouts, and launcher data compatible
  with RC1.

No gameplay timer code was changed.
