# 2.3.3 — first-frame savestate fix

The change fixes the frame where Mario disappears immediately after loading a
state. It does not change the timer or the state compression format.

1. Save in Plaza, move, then load. Mario and FLUDD should appear on the first
   restored frame, with no shadow-only flash.
2. Hold Load, then release it. Mario should remain visible while held, and play
   should resume normally when released.
3. If you already have a convenient state while riding Yoshi or a Blooper,
   check one load there too. There is no need to prepare one specially.

For any new timing, use **freeze to first visible Mario frame**. The previous
build's comparable load-1/2 result was **0.300 seconds**; 0.267 seconds ended
on the invisible-Mario frame. Another full level-loading test is unnecessary
for this change.
