# Moonshine 2.3.3 — latest fixes to test

Please include your game region, Wii/Wii U/Dolphin and launcher build checksum with any problem. One clear check per item is enough.

- **Streaking death restart:** start Ricco 4 Reds through Streaking, die, and press your normal restart shortcut. It should restart promptly and count the failed attempt once.
- **PAL Fast Text:** talk to an NPC with Fast Text on. The missing-message error should be gone. Turn it off and check ordinary dialogue still works.
- **Ghost appearance:** watch a ghost using spray and hover. Check the body lighting, arms and FLUDD movement. If convenient, compare Mario, Piantissimo and Shadow Mario; report the appearance/nozzle that looks wrong.
- **Savestates:** in Delfino Plaza, save three different positions, then load each one. Replace one slot and confirm the other two still load correctly. A short TAS or ghost continuation should survive a load as before.
- **Savestate timings, if recording:** time saves from the timer freezing to it moving again; time loads from the freeze to Mario's first visible frame. Include all three slots and say whether a slot was empty or being replaced. Please keep Wii and Dolphin results separate.
- **Moving platform, if you already have a suitable ghost:** Watch a recording that hangs from a moving platform's ledge. Check whether the platform responds before the ghost climbs up. No need to record a new run just for this.
- **Loading speed:** compare one familiar level load/reset with the previous build. Report the wait after Launch Game separately from loading during play.

The QFT timer code has not changed. If reporting the 0.001-second discrepancy, include the displayed time and the exact start/end frames used in the video comparison.
