# Moonshine V2.2.0 Pre-Release 1 "The House Always Wins"

This prerelease begins the V2.2 optimization and research cycle from the local
Moonshine V2.1.1 "Hot Streak" release state.

## Critical launcher repair

- Replaced the first PR1 package's mixed-layout FreeType archive. That archive
  rebuilt only the TrueType driver after removing a private structure field,
  while the unchanged SFNT module still expected the old layout. At launcher
  shutdown it treated the font's `glyf` length as a pointer and raised a DSI
  before JP or PAL could enter gameplay. The compatible layout is restored and
  now has a release test that reads the PowerPC driver record directly.

## In-game menu

- The Binds page is split into labelled Actions, Menu, Savestates, Warps &
  Restarts, Display, and Attempt Counter sections.
- C-stick left and right jump between those sections, matching the other long
  menu pages.
- Settings now has a dedicated `RNG Control` page. It moves the existing
  `Any fruit opens Yoshi eggs` and `Pattern selector` settings under labelled
  Yoshi Eggs and Patterns sections without changing their saved keys or
  behavior. New King Boo, Petey, Ricco Crane, and Ricco Fruit Machine sections
  keep each control separate and make their persisted state explicit.

## RNG controls

- King Boo's roulette alternates fruit and a guaranteed enemy result, starting
  with fruit in every fresh fight. Retail roulette setup, animation,
  anti-repeat logic, and RNG consumption still run. The phase advances only
  after the completed three-reel result is consumed, so skipping or aborting a
  no-fruit cycle cannot grant the next fruit early.
- Bianco 5 Petey can skip every tornado decision while preserving the retail
  RNG advance.
- Bianco 5 Petey can follow the authored N1 -> S1 -> S2 -> S3 route. N1 remains
  the normal first destination; a longer fight uses only authored transit
  edges before repeating S1 -> S2 -> S3.
- Each of Ricco's five cranes receives one stable random speed per stage.
  Slowest, Slow, Medium, Fast, and Fastest select from 1-20%,
  21-40%, 41-60%, 61-80%, and 81-100% of the native maximum respectively.
  The existing crane initialization RNG call supplies the roll, so no extra
  global RNG calls or per-frame speed jitter are introduced.
- Ricco's fruit machine can be set to `Durians only`. All three retail
  allocation attempts remain available, each reached selector still advances
  the original RNG once, and the two launch-velocity rolls remain untouched.
- Enabling either Petey control or King Boo's alternating roulette immediately
  invalidates the current IL for PB, Records, split, streak, and playlist
  credit. Creation is locked while one is active; Sunshine's HUD, FLUDD water,
  and Moonshine overlays turn pure red, and a persistent bottom-right
  `INVALID IL` marker is drawn last. Turning every boss control Off restores
  the exact pre-warning colours, including across same-scenario savestate
  loads.
- Successfully using `Spawn Yoshi Anywhere` or `Regrab Last Held Object` also
  invalidates the current IL. Merely pressing an unusable action does not, and
  these one-shot assists do not enable the persistent red boss warning.

## Memory and code-space work

- The JP font-conversion buffer now uses an unused, bounded MEM2 runtime slot
  instead of 512 bytes of injected MEM1 BSS.
- Mod V2 files omit their all-zero BSS tail and explicitly clear the complete
  runtime image on every boot or in-session reset.
- The persistent savestate controller is placement-constructed in the mod's
  existing fixed reservation, returning 56 payload bytes plus allocator
  overhead to Sunshine's pressured system heap.
- The launcher keeps 2,373 of the source font's 3,069 cmap mappings in a
  deterministic subset. The TTF falls from 318,392 to 189,844 bytes and its
  ZIP from 181,041 to 117,227 bytes; the source has no CJK, Thai, or Myanmar
  mappings.
- The one-colour stock background is procedural, and retained status frames
  now use the EFB directly. Together these remove two 1,228,860-byte 640x480
  texture allocations from the default launcher path.
- The custom-PNG decoder keeps its 4 KiB row only in its decode stack frame,
  removing 4,128 bytes of loader BSS including alignment. Its 4,224-byte frame
  remains far below the fixed 128 KiB launcher stack.
- Optional theme MP3 data uses the first 4 MiB of the already-reserved snapshot
  MEM2 window while the launcher is alive instead of consuming MEM1 heap. It
  is stopped, cache-invalidated, and repurposed before the game; this moves the
  payload rather than reducing total memory.
- The DOL packer omits 54,880 bytes of unused unwind metadata from `boot.dol`.
- The ARM crash reporter reuses its boot-time probe buffer for live captures,
  removing a redundant 2 KiB kernel allocation without changing the report
  format.
- Mutually exclusive personal/imported ghost scans share one private ARM
  workspace. Serialized-lifetime checks and cleanup preserve behavior while
  removing 3,552 linked kernel BSS bytes.
- Bluetooth heap requests now round against the correct alignment, so future
  5-11-byte allocations cannot be under-sized; no Bluetooth pool was reduced.
- The embedded ARM kernel now decompresses straight into its final bounded
  MEM2 window, removing an exact 452,964-byte V2.1 temporary launcher
  allocation and the following full-image copy.
- FatFS paths now use bounded, locale-free UTF-8/UTF-16 conversion, support
  supplementary Unicode correctly, and reject malformed or overlong names
  instead of truncating them. This removes 1,728 bytes of ARM BSS and 7,772
  bytes of ARM code while saving 800 code bytes and 1,536 BSS bytes in the PPC
  launcher.
- Multilingual launcher text is decoded straight from UTF-8 scalars. This
  removes the PPC locale dependency and every temporary `wchar_t` heap
  allocation from draw and width calls; an isolated current-source build
  removes 7,104 bytes from `boot.dol` and 672 bytes of BSS.
- The launcher links only the seven FreeType modules needed by its bundled
  TrueType face. Exhaustive host rendering matched the full initializer, and
  the paired cross-build removes 255,456 bytes from `boot.dol` with unchanged
  BSS. A later 23,040-byte attempt to remove the deprecated hinter was rejected:
  rebuilding only one archive member changed a private shared layout even
  though its 26,114 rendered glyph cases matched. PR1 keeps the coherent
  pre-existing layout.
- IPL-font loading now streams through one aligned 256-byte stack chunk into
  its unchanged MEM2 destination. This removes an exact 327,680-byte temporary
  heap allocation; simultaneous stack-plus-heap demand falls by 327,352 bytes
  before allocator metadata.
- Repeated GameCube IPL patch writes now use compact tables and shared helpers.
  Exact address/value/order oracles cover every supported layout, and the
  `-Os` object is 456 bytes smaller.
- Loader ZIP checks use a zlib-compatible nibble CRC with a 64-byte table.
  This drops the unused combine closure and 8 KiB zlib table, removing 10,080
  bytes from `boot.dol` with identical incremental and null-input semantics.
- The PPC launcher now defaults to `-Os`; a reproducible paired build reduced
  `boot.dol` by 35,328 bytes and its static MEM1 span by 35,008 bytes versus
  `-O3`, which remains available as an override.
- The generic Triforce detector uses one ordered data table instead of 15
  duplicated read/log/save branches. The O3 object loses 2,705 allocated bytes
  and its stack frame shrinks by 240 bytes without changing any signature,
  label, save path, size, or first-match action.
- Fixed-size launcher paths now reject truncation. The titles parser also caps
  its 740-row array and rejects overlong lines instead of writing a 741st row
  or turning one malformed line into multiple false titles.
- The release includes a twelve-pass size and memory audit. Measured deltas and
  rejected unsafe candidates are recorded in `v2.2.0-size-audit.md`.

## Remaining RNG research

- RNG ownership and exact three-region control sites for enemies, bosses,
  Ricco machinery, birds, and water are mapped in
  `v2.2.0-rng-manipulation.md`. King Boo alternating-fruit, Bianco 5 Petey's
  no-tornado/route controls, Ricco crane speed bands, and the Ricco
  Durians-only fruit launcher are implemented in this prerelease; broader
  bird, enemy, and water controls remain research only.
