# Moonshine V2.2.0 Release Candidate 3

## The House Always Wins

RC3 adds the requested achievement expansion and makes IL PB safety much easier
to understand. The active catalog now contains exactly **210 achievements**.

## PB safety and achievement presentation

- Added **Settings > PB Safety**. It lists every saved setting that can stop an
  IL PB, shows how many are currently blocking PBs, and offers **Fix** and
  **Fix all** shortcuts.
- PB-affecting options are marked directly in their normal Settings pages.
  Unsafe values are shown in red as **PB OFF**.
- Achievement popups now show both the category and tier.
- Retired the exact duplicates **Chuckster Change**, **No Kidding**, and
  **Tower Titan**. Their old save IDs remain reserved so existing progress
  stays compatible, and any prior unlock moves to the surviving achievement.

## Stability polish

- Ghost-race achievements now bind the selected opponent on the very first
  attempt as well as every restart.
- Turning on Intro Skip or Fast Forward during an already-assisted boss run
  remains recorded as a disqualifier, even if it is turned off before the
  finish.
- Savestates now preserve the complete safe game-state ranges on JP, US, and
  PAL while continuing to exclude live audio and movie-player state.
- A damaged savestate header is rejected before it can restore anything, and a
  load requested while the memory card is busy now waits for the transaction
  instead of failing almost immediately.
- Savestate loads preserve the settings that are live now, including Fast Text
  and fruit-timeout patches, instead of restoring the old toggle state hidden
  inside copied game memory.
- Savestate heap pointers and copy ranges are checked before they are touched,
  so a damaged or stale snapshot fails safely.
- Stage Loader targets survive a temporary SD write error and retry at a safe
  interval instead of silently losing the edit.
- Settings and layout saves now use a recoverable temp-and-backup transaction.
  Incomplete, oversized, read-only, or suspicious files are left untouched;
  delayed saves remain queued and retry without losing later menu edits.
- Buttons used by any open mod-menu page no longer leak into gameplay actions,
  including when the player has rebound the menu toggle.
- The JP, US, and PAL Dolphin patch layouts now include every current gameplay
  hook; all three source-free patches build from their verified clean discs.
