# Moonshine V2.2.0 Pre-Release 3

## The House Always Wins

- Merged the official Moonshine V2.1.1 release, including its corrected Bianco 2 level entry.
- Bianco 2 now splits on the high rollout, the start of the Petey FMV, and each of Petey's three hits.
- Retargeted the Bianco Hills Skeeter control to the Skeeter left of the windmill.
- Added four-pattern controls for the Gelato 6 red coin fish and blue birds.
- Reorganised Timer and RNG Control into smaller nested menus.
- Added Wallkick-style Creation editors for the Rollout and Dust displays.
- Restored the classic input display as the default while retaining its Creation editor.
- Prevented the pause menu and save box from reacting while the Moonshine menu is open.
- Preserved the existing Petey, King Boo, Ricco crane, Ricco fruit machine, invalid-IL warning, and QFT freeze features.

Gameplay timer behaviour was not changed.
