`Retail` means the normal, unassisted game behaviour.

## Starting the game and using the menus

- [ ] **1. Boot and version:** Start the packaged launcher and reach gameplay.
  The launcher says `V2.2.0 Pre-Release 4 "The House Always Wins"`, and the
  Records page says `Moonshine V2.2.0 PR4`.

- [ ] **2. Supported regions:** Boot every region available to you. JP, US,
  and PAL should all reach gameplay without an error screen.

- [ ] **3. Settings layout:** Open every page inside Settings. The groups and
  page names should make sense, every page should be easy to enter and leave,
  and no rows should overlap or disappear while scrolling.

- [ ] **4. RNG controls layout:** Check General patterns, Boss fights, Ricco
  Harbor, and Birds & fish. Ricco Harbor should clearly show `Crane speed` and
  `Fruit machine`. Normal choices should be called `Retail`. There should be
  no Skeeter option anywhere.

- [ ] **5. Saving menu changes:** Change one setting and one button bind, close
  the menu, reboot, and check them again. Both changes should still be saved.

- [ ] **6. Menu blocks the game:** Open Moonshine while the pause menu or a
  save box could react to the controller. Start and the directions should
  control only Moonshine until its menu is closed.

## Bianco 2 IL and splits

- [ ] **7. Correct level:** Starting the Bianco 2 IL should use the Bianco 1
  map with the Bianco 2 mission. It must not send you to the normal Bianco 2
  map entry.

- [ ] **8. Correct split order:** Complete the Bianco 2 IL. Its four splits
  should be: high rollout, Petey hit 1, Petey hit 2, and Petey hit 3.

- [ ] **9. No FMV split:** Starting the Petey FMV should not create a split.
  Each Petey hit should create exactly one split, with no duplicates.

- [ ] **10. Existing records:** If this SD already has Records or split times,
  check a few levels other than Bianco 2. Their old results should still be
  present. Bianco 2 split history may start fresh because its split order
  changed.

## King Boo and Petey

- [ ] **11. King Boo fruit cycle:** Enable `King Boo fruit cycle` and complete
  five roulette results. They should be fruit, no fruit, fruit, no fruit,
  fruit. Cancelling or failing to finish a no-fruit result must not allow the
  next fruit early. `Retail` should restore normal results.

- [ ] **12. Petey tornado:** Enable `Disable Petey tornado` in Bianco 5. Petey
  should never use the tornado. Turning it off should restore normal behaviour.

- [ ] **13. Petey flight route:** Enable the Petey route. He should always go
  to N1 first, then land at S1, S2, and S3 in that order. A longer fight may
  use other points only while travelling; it should not land at them. `Retail`
  should restore the normal route.

- [ ] **14. Invalid-run warning:** Turn on each King Boo and Petey control one
  at a time. The HUD and Moonshine displays should turn bright red, `INVALID IL`
  should stay visible at the bottom right, and Layout editor should be
  unavailable. Turning every boss control off should immediately restore all
  colours and Layout editor.

- [ ] **15. Warning after a savestate:** Save while a boss control is active,
  turn the control off, then load that savestate. The warning should match the
  currently loaded setting and must not leave normal HUD pieces stuck red.

## Ricco Harbor

- [ ] **16. Crane speed:** Try Slowest, Slow, Medium, Fast, and Fastest. Every
  crane should choose one speed inside the selected fifth of its normal range
  and keep that speed until the stage is restarted. Different cranes may pick
  different speeds. `Retail` should restore normal crane movement.

- [ ] **17. Fruit machine:** Select `Durians only` and use the Ricco fruit
  machine several times. Every fruit it successfully launches should be a
  durian, while launch direction and speed may still vary. `Retail` should
  restore the normal fruit selection.

## Yoshi eggs, fish, and birds

- [ ] **18. Yoshi egg option:** `Any fruit opens Yoshi eggs` should still let
  every fruit type open an egg. Turning it off should restore the egg's normal
  required fruit.

- [ ] **19. General pattern selector:** The existing Pattern selector should
  still work wherever you normally use it. Its setting and the Yoshi egg
  setting should both live under General patterns and remain saved after
  closing the menu.

- [ ] **20. Gelato 6 red-coin fish:** With `Retail`, restarts should give normal
  random openings. Test Patterns 1, 2, 3, and 4 at least twice each. Every
  selected pattern should repeat its own opening after a restart.

- [ ] **21. Delfino blue-coin bird:** Test a known blue-coin bird in Delfino
  Plaza with `Retail`, then Patterns 1 through 4. Restart before every attempt.
  A selected pattern should repeat, while `Retail` should restore normal
  movement.

- [ ] **22. Gelato blue-coin bird:** Repeat the previous bird check with a
  known blue-coin bird in Gelato Beach.

- [ ] **23. Pinna blue-coin bird:** Repeat the bird check with a known
  blue-coin bird in Pinna Park.

- [ ] **24. Pattern safety:** Fish and bird choices should not change unrelated
  enemies or normal birds. They should not turn the HUD red, show `INVALID IL`,
  or disable Layout editor.

## Practice displays and QFT freezes

- [ ] **25. Rollout display:** Perform rollouts while holding A for 1, 2, 3,
  4, 5, and more than 5 frames. The display should show `1f` through `5f`;
  longer holds should still show `5f`.

- [ ] **26. Dust display:** Land and roll out after delays of 1 through 6
  frames, then do one clearly late rollout. The display should show the first
  six timings separately, then `Late`.

- [ ] **27. Display editors:** Wallkick, Rollout, and Dust should each allow
  position, size, colours, background, and reset to be edited. Save a visible
  change, close the menu, and confirm it remains. Reset should restore the
  default look.

- [ ] **28. QFT menu:** Timer & splits should contain a separate `QFT freezes`
  page. Scroll through it and confirm the existing freeze choices are still
  present.

- [ ] **29. Airgrab freeze:** Enable the Airgrab freeze, stand still with empty
  hands, and hold B. QFT should freeze only during Mario's airgrab animation
  and continue afterward. Moving normally or holding an object should not
  falsely trigger it.

- [ ] **30. Classic input display:** The classic controller display should be
  available, react to every button and stick correctly, and still work with
  its Layout editor controls. If an old setup saved it as hidden, turn it on
  first.

## Assisted actions and important regressions

- [ ] **31. Spawn Yoshi and Regrab appearance:** Successfully use Spawn Yoshi
  Anywhere and Regrab Last Held Object in separate attempts. These actions
  must not turn the HUD red, show `INVALID IL`, or disable Layout editor.

- [ ] **32. Spawn Yoshi and Regrab eligibility:** Finish an IL after successfully
  using either action. The assisted attempt should not earn a PB, Records,
  split, streak, or playlist result. Pressing an action when it cannot do
  anything should not invalidate the attempt.

- [ ] **33. Savestates:** Save and load in a normal stage, shortly after
  entering a stage, after talking to an NPC, and from the pause menu. Mario,
  enemies, coins, and controller state should return correctly without a
  crash. If a boss control stays enabled, its saved sequence should also resume
  from the saved point.

- [ ] **34. IL and ghost regression:** Complete one short normal IL and one
  ghost attempt without assists. Splits, PB saving, Records, ghost recording,
  ghost playback, and result popups should still work normally.

- [ ] **35. Normal timer regression:** With all new controls set to `Retail` or
  off, run a familiar IL and compare the normal timer and QFT behaviour with
  the previous release. They should behave the same.
