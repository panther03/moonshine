# Moonshine V2.2.0 Pre-Release 4 test list

Write **PASS** or **FAIL** beside each item. For a failure, add the game region and one short sentence.

- [ ] **Boot and version:** The game boots. The launcher says Pre-Release 4 and the Records page says PR4.
- [ ] **Bianco 2 level:** Starting the Bianco 2 IL loads the Bianco 1 map with the Bianco 2 mission.
- [ ] **Bianco 2 splits:** The splits are high rollout, Petey hit 1, Petey hit 2, and Petey hit 3. Starting the FMV does not split.
- [ ] **Settings:** Every Settings page is easy to understand, enter, and back out of. Ricco Harbor shows `Crane speed` and `Fruit machine`, with `Retail` as the normal choice.
- [ ] **Skeeter removed:** There is no Skeeter option anywhere in RNG controls.
- [ ] **Boss warning:** Petey or King Boo control makes the HUD red, shows `INVALID IL`, and disables Layout editor. Turning the control off restores everything immediately.
- [ ] **Yoshi and Regrab:** Spawn Yoshi Anywhere and Fruit Regrab do not make the HUD red and do not show `INVALID IL`.
- [ ] **Quick regression:** King Boo, Petey, Ricco crane, Ricco fruit machine, Rollout display, Dust display, Airgrab QFT freeze, and the classic input display still work.

The bird and fish controls have their own tester sheet and do not need to be checked in this pass.
