## Small fixes

- PAL Fast Text supplies `!!!` at the existing audited parser hook. JP keeps
  its three full-width exclamation marks and US keeps its previous literal.
- Returning through retail `APP_STATE_DONE` (context 4) ends the active run
  session before the intro or file select can resume it. This is the path
  taken by console soft reset, including Intro Skip. Ordinary deaths, level
  resets, movies and episode transitions retain the session. The condition
  runs on entry to that context, before the non-stage-director early return.
  It does not repeatedly cancel new sessions deliberately started from the
  Intro-Skip file-select menu.
  It uses the existing session cancellation and preserves saved settings,
  playlists and records. The decomp reference is `System/Application.cpp`,
  `TApplication::proc`; host checks execute the actual entry guard.

## Validation scope

Further performance results and final build receipts are recorded under
`build/v2.3.3-feedback5`. No new Wii time is claimed until measured on hardware.
The ordinary QFT source and memory reservations remain protected.

The selected load optimization keeps CRC arithmetic in PowerPC's native word
order and shares a faster, exact Adler calculation between both codecs. Both
checks still cover every byte. See `v2.3.3-state-checksum-speed.md` for arithmetic,
corruption tests and isolated comparisons, and
`v2.3.3-savestate-lifecycle-feedback5.md` for the complete operation profile.
Existing readiness checks, graphics barriers and restoration filters remain.

The ISO cache now keeps storage-read destinations aligned. The real PAL trace
avoids 17,732,608 bytes of temporary-buffer copying with identical returned
data and device-read counts; `v2.3.3-iso-dma-alignment.md` records its scope.
