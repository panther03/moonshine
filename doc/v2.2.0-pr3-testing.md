# Moonshine V2.2.0 Pre-Release 3 test list

Write **PASS** or **FAIL** beside each item. For a failure, add the game region and one short sentence describing what happened.

- [ ] **Boot and version:** JP, US, and PAL boot where available. The Records page and launcher both say Pre-Release 3.
- [ ] **Bianco 2 level:** Starting the Bianco 2 IL loads the Bianco 1 map with the Bianco 2 mission, not the Bianco 2 map.
- [ ] **Bianco 2 splits:** The first split is the high rollout. The second happens once when the Petey FMV begins. The next three happen on Petey hits 1, 2, and 3.
- [ ] **Skeeter:** Choose Left, Middle, and Right one at a time, restarting Bianco 1 or 2 after each choice. Only the Skeeter left of the windmill, near X 4000 and Z -10000, should take the chosen direction. Off should restore normal randomness.
- [ ] **Boss invalid warning:** Petey or King Boo control makes the HUD red, shows `INVALID IL`, and disables Creation. Turning the control off restores everything immediately.
- [ ] **Boss behaviour:** Petey never uses the tornado and follows the three selected spots. King Boo alternates fruit, no fruit, fruit, no fruit without allowing the required empty cycle to be skipped.
- [ ] **Ricco controls:** The crane still respects all five speed bands. Durians Only on the fruit machine produces durians; Off restores normal fruit.
- [ ] **Gelato 6 fish:** Patterns 1 through 4 produce four repeatable red coin fish openings after restarting the level. Off restores normal randomness and none of these choices show `INVALID IL`.
- [ ] **Gelato 6 birds:** Patterns 1 through 4 produce four repeatable blue-bird openings after restarting the level. Off restores normal randomness and none of these choices show `INVALID IL`.
- [ ] **Timer menus:** Timer has a QFT Freezes submenu, every old QFT option is still present, and Airgrab freeze still works.
- [ ] **RNG menus:** General, Boss Assists, Bianco Hills, Ricco Harbor, and Gelato Beach pages are easy to enter and back out of without losing a changed setting.
- [ ] **Rollout and Dust:** Both displays still report the correct frame count. Each has the same position, size, colour, background, and reset editing available for Wallkick.
- [ ] **Classic input display:** The old-style controller display is visible on a fresh setup, still reacts correctly, and its Creation controls still work. If an existing INI saved it as hidden, turn Input Display on first.
- [ ] **Menu blocks the game:** While the Moonshine menu is open, Start and directions must not open or move the pause menu, and directions must not move a save-box choice.
- [ ] **Regression:** Spawn Yoshi Anywhere and Fruit Regrab still show the invalid-IL warning. Turning them off restores the normal HUD.
