## Starting the game and using the menus

- [ ] **1. Boot and version:** Start the packaged launcher and reach gameplay.
  The launcher should say `V2.2.0 Pre-Release 5 "The House Always Wins"`, and
  Records should say `Moonshine V2.2.0 PR5`.

- [ ] **2. Supported regions:** Boot every region available to you. JP, US,
  and PAL should reach gameplay without an error screen.

- [ ] **3. Settings menu:** Open every Settings page. Nothing should overlap or
  disappear. Section headings should use visible words such as `AND`, with no
  blank gap where JP cannot draw a symbol.

- [ ] **4. Fast section navigation:** At the main Settings page, use C-stick
  left and right. It should jump between Gameplay and Practice, Timing and HUD,
  and Layout and Controls. The same shortcut should jump between sections on
  the ILs page.

- [ ] **5. Saving choices:** Change one setting and one button bind, close the
  menu, reboot, and confirm both changes remain.

- [ ] **6. Menu owns the controls:** Open Moonshine while the pause menu or a
  save box is present. Directions and Start should affect only Moonshine until
  its menu is closed.

## RNG menu and IL list cleanup

- [ ] **7. Shine an RNG option:** Highlight each page of RNG Controls and press
  X on at least one row. The row should appear in Shined. Un-Shine it with X
  again. Include a boss option and a fish or bird option.

- [ ] **8. Shined choices persist:** Shine one RNG option, close the menu,
  reboot, and confirm it is still in Shined. Its actual Retail or forced value
  must not change when it is Shined.

- [ ] **9. GBS location:** Open ILs and find `Gelato GBS` directly under the
  Gelato section. It must no longer appear at the bottom near Corona.

- [ ] **10. GBS still works:** Start Gelato GBS and finish it. Its existing PB,
  Records, split, and playlist identity should still be Gelato GBS rather than
  another Gelato IL.

## Bianco 2 and the PR4 display fixes

- [ ] **11. Bianco 2 start:** Starting the Bianco 2 IL should use the Bianco 1
  map with the Bianco 2 mission. It must not send you to normal Bianco 2.

- [ ] **12. Bianco 2 splits:** Finish the IL. Records should contain five timed
  segments in this order: high rollout, Petey hit 1, Petey hit 2, Petey hit 3,
  and the final Shine. Each Petey hit should advance exactly once.

- [ ] **13. No FMV split:** Starting the Petey movie should not add a segment.
  The next segment after the rollout should be Petey hit 1.

- [ ] **14. Dust on normal ground:** Land on dry ground and roll out after 1
  through 6 frames, then late. Dust should show the same results as before.

- [ ] **15. No Dust on waterslides:** Enter a real waterslide or slide across
  wet ground and roll out. Dust must not show a result for that
  landing.

- [ ] **16. Classic input sticks:** Move both sticks to every edge. Their dots
  should reach the full gate instead of stopping short.

- [ ] **17. Small classic Start button:** Shrink the classic input display to
  its minimum size and press Start. The centre button should still visibly
  light up.

## Ghost race saving

- [ ] **18. Race a saved ghost:** Choose a saved library ghost and select
  `RACE`. Start a new attempt against it and make the challenger visibly
  different from the saved opponent.

- [ ] **19. Save the challenger:** During or after that race, use the Ghosts
  Save action. The name and saved run should belong to the new challenger, not
  the opponent selected for the race.

- [ ] **20. Race playback remains intact:** The selected opponent should still
  play normally while racing. Loading it must not stop or erase the current
  challenger recording.

## Streaking

- [ ] **21. Cleaner Streaking list:** Set Stage Loader to Streaking and inspect
  the IL list. Hidden Shines and 100-coin Shines should not be offered as the
  episode you start from. They should still exist in the normal IL and playlist
  lists.

- [ ] **22. Any Shine in the episode counts:** Start a streak for one episode,
  then collect a different Shine that is available in that same episode. The
  streak should count it as a success and restart the selected episode.

- [ ] **23. Wrong episode still fails:** Start a streak, leave for a different
  episode, and collect its Shine. The streak should fail rather than count it.

- [ ] **24. Normal playlists stay exact:** In normal Stage Loader mode, a
  playlist entry should still require its exact finish. The wider rule applies
  only to Streaking.

## Pinna fruit and coin display

- [ ] **25. Hidden Pinna items:** Enable `Pinna fruit and coins` under HUD and
  Displays, then enter the Pinna Beach map. Unrevealed fruit and coins that can
  be uncovered by spraying should have clear labels at their hiding spots.

- [ ] **26. Markers disappear correctly:** Spray several marked spots. Each
  marker should disappear as its item is revealed, without hiding markers for
  other unrevealed items.

- [ ] **27. Pinna-only display:** Leave Pinna Beach. These fruit and coin labels
  must not appear in unrelated stages. Turning the option off should remove
  every label immediately.

## Enemy hurtboxes

- [ ] **28. Normal enemies:** Enable `Enemy hurtboxes` under HUD and Displays.
  Enemies should show green cylinders around the areas that receive attacks.
  The display must not change how enemies behave or take damage.

- [ ] **29. Eely-Mouth teeth:** Enter the Eely-Mouth fight and inspect all eight
  teeth. Every live tooth should have a useful hurtbox display. A destroyed
  tooth should stop showing a live hurtbox.

- [ ] **30. Hurtbox safety:** Try the option in a crowded stage and during a
  boss fight, then turn it off. There should be no crash, major slowdown, or
  leftover lines.

## Position save and load

- [ ] **31. Set the binds:** Open Button Binds and find the new Position
  section. Assign separate combos to `Position: save` and `Position: load`.
  They are intentionally unbound on a fresh setup.

- [ ] **32. Restore position:** Save a position, move Mario and the camera, and
  load it. Mario's XYZ position, facing direction, camera direction, and camera
  distance should return together.

- [ ] **33. Held-button behaviour:** Hold the load combo while trying to move.
  Mario should remain at the saved point until the combo is released, matching
  the old Dan Salvato code.

- [ ] **34. IL eligibility:** Merely saving a position should not invalidate an
  IL. Successfully loading a position should prevent that attempt from earning
  a PB, Records result, split result, streak result, or playlist result.

## Important regressions

- [ ] **35. Boss RNG warning:** King Boo and Petey controls should still turn
  assisted HUD pieces red, show `INVALID IL`, and disable Layout Editor. Turning
  every boss control off should immediately restore the normal HUD.

- [ ] **36. Other RNG controls:** Ricco crane speed, Ricco durians, Gelato fish,
  and blue-coin bird patterns should retain their PR4 behaviour. Fish and bird
  choices must not show `INVALID IL`.

- [ ] **37. Assisted actions:** Spawn Yoshi Anywhere and Regrab Last Held Object
  should still work without making the HUD red. A successful use should still
  remove IL credit.

- [ ] **38. Savestates:** Save and load in a normal stage, after talking to an
  NPC, and from pause. Mario, enemies, coins, and controller state should return
  without a crash.

- [ ] **39. Normal IL and ghost:** Complete one short unassisted IL and one
  ghost attempt. PBs, Records, splits, ghost recording, ghost playback, and
  result messages should work normally.

- [ ] **40. Timer regression:** With the new displays and assists off, run a
  familiar IL. The normal timer and QFT should behave exactly as in PR4.
