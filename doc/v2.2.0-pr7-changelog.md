# Moonshine V2.2.0 Pre-Release 7

## The House Always Wins

PR7 fixes the remaining PR6 tester findings and makes the growing settings
menus easier to understand.

### IL and ghost fixes

- Full Reds now keeps FLUDD available throughout the full episode-to-secret
  route, matching Secret Reds.
- Fixed Full Reds PB completion across the parent-to-secret transition,
  including Pinna 6 from both the IL list and Stage Loader.
- Reworked Bianco 2's Petey hit detection around the actual damage event, with
  a live-health fallback, so each of the three hits advances exactly once.
- Fixed ghost races so loading an opponent cannot preserve and later save an
  unrelated partial run.
- Fixed child-stage ghost races such as Noki 6 Secret so the selected opponent
  stays pinned and the new challenger records and saves as a complete run.

### Display fixes

- Dust no longer reports during Mario's actual water-slide state, including
  its first frame.
- Enlarged the classic input display's Start button at normal and tiny scales.
- Hardened hurtbox and checkpoint drawing against off-screen, near-camera, and
  oversized geometry that could cover or corrupt the screen.
- Made Ricco 2 checkpoints easier to see with brighter colours, crosshairs,
  backing plates, and larger labels.
- Restored Pinna 8's balloon counter to its retail position and keeps the
  Moonshine timer above it.

### Menus and memory

- Added short descriptions to Settings categories, pages, individual options,
  Ghost controls, Records options, and Layout Editor rows.
- Reorganised HUD and Displays into Movement Displays, Practice Visuals, and
  Other HUD pages.
- Added scrolling to the Settings hub so every category remains reachable.
- Expanded the mod's working area inside its existing reserved memory block;
  this takes no additional memory away from the game or attachment storage.

The QFT timer implementation was not changed.
