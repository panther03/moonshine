# Moonshine V2.2.0 Pre-Release 6 — optional visual checks

These are the useful extra checks for someone who knows the stages. They are
optional and do not need to be repeated by every tester.

- [ ] Find spray-hidden fruit and coins outside Pinna. Check `Both`,
  `Fruit`, `Coins`, labels on, labels off, and `Off`.
- [ ] Spray several marked spots. Only the objects actually revealed lose
  their markers.
- [ ] Compare enemy hurtboxes in `Wireframe`, `Transparent`, and `Solid` in one
  crowded stage. Turning the option off leaves no shapes behind.
- [ ] In Eely-Mouth, compare `All enemies` with `Eely teeth only`. Eely's body
  stays hidden in both cases, all live teeth are usable, and broken teeth stop
  appearing.
- [ ] In Ricco 2, check every visible race checkpoint against the route rather
  than only the first gate.
- [ ] In Pinna 8, check the balloon count during the whole roller-coaster ride,
  including while the timer has wide minute digits.
