# Moonshine V2.2.0 Pre-Release 8 — optional extra checks

These are optional stress checks. One person does not need to run all of them.

- [ ] Try one Full Reds route other than Pinna 6. FLUDD remains available in
  the secret, the Full Reds PB is used, and leaving the route restores the
  player's normal FLUDD-in-secrets setting.
- [ ] In Pinna 8, watch the timer and balloon counter from their first frame
  through the end of the ride. Neither display jumps, overlaps, or leaves the
  screen.
- [ ] In Ricco 2, view every checkpoint from far away, from inside it, and with
  the camera pressed against it. The transparent volume remains calm and never
  turns into a large opaque polygon.
- [ ] Run Bianco 2 twice. The FMV split advances exactly once at the Windmill
  movie handoff, every successful Petey stomp advances one split, and ordinary
  movement or failed stomps do not advance anything.
- [ ] Repeat the six main checks on a second game region if one is available.

The previously passed PR7 display and menu checks do not need another round.
