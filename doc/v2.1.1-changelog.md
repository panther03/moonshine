# Moonshine V2.1.1

## Moonshine

- The mod and its user-facing interface are now **Moonshine**.
- The Homebrew Channel entry is **Moonshine Launcher**, using the new Moonshine
  banner. The launcher build line is **Moonshine V2.1.1 "Hot Streak".**
- Release Candidate and DELTA branding has been removed; **Hot Streak** remains
  the release subtitle.

## Fixes and additions

- Fixed Pinna 8 PBs not saving after the rollercoaster return.
- Fixed collected Pinna 8 and its persistent coaster-complete phase sending
  practice starts to the Shine-spawn sequence instead of the park entrance.
- Fixed normal resets, Streaking retries, and savebox-delayed retries after the
  Pinna 8 Shine returning to the post-coaster section instead of park phase 1.
- Fixed Pinna 8 sometimes restarting a few seconds into the rollercoaster.
- Loading-zone level splits now use the entry frame instead of the following
  transition-completion frame.
- Split deltas are kept directly to the right of the QFT freeze.
- JP now draws a real `+` sign for positive split deltas.
- Added a persistent **Level splits** on/off setting. Turning the overlay off
  does not stop segment statistics from being recorded.
- Added a persistent **Streak auto-reset** setting. With it off, both a target
  success and a target miss remain on the save box; leaving the save box starts
  the next attempt.
- The Sunshine timer moves upward while Pianta-cleaned, balloon, or red-coin
  mission counters are visible, then returns to its configured position.

## Compatibility

- Existing settings, PBs, split statistics, Records, ghosts, playlists, themes,
  targets, and BGM remain compatible.
- Release downloads use the Moonshine name, including `moonshine_launcher.zip`
  and `moonshine_emu_<region>_<version>.bps` emulator patches.
- The launcher app folder is now `apps/moonshine_launcher`. Existing installs
  should rename `apps/susamune_launcher` before extracting the update, which
  preserves custom launcher themes and BGM and avoids duplicate HBC entries.
- Durable storage names are intentionally unchanged. Keep `susamune.ini` and
  existing `susamune_*` data files in place.

## Known issue

- Bianco 2 practice splits remain unreliable and are deferred to V2.2.0.
