    This page has to be served over HTTP.
    
      
    
        It is built from ES modules, and browsers refuse to load those from a
        file:// path — so the page renders but nothing is wired up. Run a server from
        the site/ directory and open the address it prints:
      
    
      
    python -m http.server 8000
    
      
    
        Then browse to http://localhost:8000. Hosted over HTTPS (GitHub Pages) it works
        as-is.
